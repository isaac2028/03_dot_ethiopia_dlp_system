# Regional Data Leak Prevention (DLP) & Communication Audit System

An organizational threat monitoring framework built for **DOT Ethiopia** to fulfill Regional ICT Lead security standards.

## Project Scope
- Implements Regular Expression (RegEx) matching pipelines to parse corporate email streams for sensitive identifiers.
- Contextually reviews personal HR documents to identify unstructured data exposure pathways.
- Computes multi-tiered organizational risk levels ("Low", "Medium", "Critical") to automate data quarantine routines.
